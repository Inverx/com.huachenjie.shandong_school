## 资料迁移说明 (Repository Migration Notice)

> **重要通知：本仓库原有项目资料已全部迁移至新的统一归档仓库。原仓库已停止维护并归档，仅作为历史研究记录保留。**

### 1. 新仓库地址

项目资料现统一整理并归档至：

**[Inverx/Reverse-Archive](https://github.com/Inverx/Reverse-Archive)**

新仓库作为 Android 逆向工程与移动应用安全研究资料的统一归档入口，按照目标软件的 Android Application ID（包名）进行分类，并进一步按照研究阶段及客户端版本组织相关资料。

其中，闪动校园相关资料位于：

`com.huachenjie.shandong_school/`

### 2. 迁移范围

原仓库涉及的项目资料已转移至新仓库，后续统一通过新仓库进行资料查阅、整理及补充。

新仓库采用统一的分层归档结构，涵盖以下研究方向：

- **原始脱壳资料：** Android DEX、Native SO 等客户端运行时提取产物。
- **静态分析：** 客户端代码结构、关键类、加固特征及算法分析资料。
- **动态分析：** Frida Hook、运行时调试及相关分析记录。
- **接口与协议：** 网络通信、数据格式、加密算法及历史协议参考实现。

具体收录内容、客户端版本及文件结构，以新仓库实际提交的资料为准。

### 3. 原仓库状态

原仓库现已停止维护并设置为 GitHub Archived 状态。

自资料迁移完成后，本仓库不再进行以下工作：

- 代码及文档更新。
- 新客户端版本适配。
- 历史模块功能维护与问题修复。
- 新版本 Release 发布。
- 后续分析资料及研究成果补充。

原仓库保留的文件及历史提交仅用于记录此前的研究过程，不再作为后续资料更新的依据。
